# Speaker-Age-Prediction-Using-Regression-Model
In this project, we worked with audio files to extract relevant features and used them to build a model that predicts the speaker's age.

Ages Includes:
Teens (ages from 13 to 18)
Twenties (ages from 19 to 29)
Thirties (ages from 30 to 39)
Fourties (ages from 40 to 49)
Fifties (ages from 50 to 59)
Sixties (ages from 60 to 69)
Seventies (ages from 70 to 79)
Eighties (ages from 80 to 89)
Nineties (ages from 90 to 99)

For this project you have to install following libraries using pip/!pip command:
os
librosa
pandas
numpy
matplotlib.pyplot
seaborn
